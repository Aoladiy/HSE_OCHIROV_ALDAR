# University Sharded DB

MongoDB sharded cluster with Python CLI and load testing.

## Requirements

- Docker with Docker Compose

## Usage

```bash
make up       # build and start the cluster (includes auto-init)
make seed     # load 5000 sample students into the database
make client   # open the console interface
make test     # run load test, saves report/load_test_results.png
make down     # stop the cluster
make clean    # stop and remove all volumes
```

Other commands:

```bash
make restart  # down + up --build
make logs     # follow logs of all containers
make ps       # show container status
make shell    # open bash in the app container
```

Note: run `make seed` before `make test` to populate students and grades
so that shard distribution charts show data for all collections.

# pg_ru_utils

Расширение PostgreSQL с утилитами для работы с российскими строковыми данными.

## Функции

### Транслитерация

| Функция                  | Описание                                               |
|--------------------------|--------------------------------------------------------|
| `ru_translit(text)`      | Кириллица → латиница (щ→shch, ё→e, й→i, ъ/ь удаляются) |
| `ru_translit_slug(text)` | Транслитерация + нормализация в URL-slug               |

```sql
SELECT ru_translit('Щербакова Екатерина'); -- 'Shcherbakova Ekaterina'
SELECT ru_translit_slug('Привет Мир!'); -- 'privet-mir'
```

### Валидация ИНН

| Функция              | Описание                                          |
|----------------------|---------------------------------------------------|
| `inn_validate(text)` | Проверка контрольной суммы (10 и 12 цифр)         |
| `inn_type(text)`     | Тип: `'юрлицо'`, `'физлицо'` или `'неверный ИНН'` |

```sql
SELECT inn_validate('7707083893'); -- true
SELECT inn_type('7707083893'); -- 'юрлицо'
```

### Валидация СНИЛС

| Функция                | Описание                                  |
|------------------------|-------------------------------------------|
| `snils_validate(text)` | Проверка контрольной суммы (алгоритм ПФР) |
| `snils_format(text)`   | Форматирование в `XXX-XXX-XXX YY`         |

```sql
SELECT snils_validate('112-233-445 95'); -- true
SELECT snils_format('11223344595'); -- '112-233-445 95'
```

### Телефоны

| Функция                 | Описание                                     |
|-------------------------|----------------------------------------------|
| `phone_normalize(text)` | Нормализация к `+7XXXXXXXXXX`                |
| `phone_validate(text)`  | Проверка формата и кода (3xx, 4xx, 8xx, 9xx) |

```sql
SELECT phone_normalize('8 (999) 123-45-67'); -- '+79991234567'
SELECT phone_validate('8 (999) 123-45-67'); -- true
```

### Маскирование

| Функция            | Описание                                      |
|--------------------|-----------------------------------------------|
| `mask_email(text)` | `ivan.ivanov@mail.ru` → `iva********@mail.ru` |
| `mask_phone(text)` | `+79991234567` → `+7999***4567`               |
| `mask_card(text)`  | `4111111111111111` → `4111 ******** 1111`     |

## Быстрый старт

Требуется Docker.

```bash
make help     # помощь с командами
make build    # собрать Docker-образ
make up       # запустить контейнер (пропускает, если уже запущен)
make test     # прогнать тесты
make examples # запустить демо-сценарии
make psql     # открыть psql-сессию
make down     # остановить контейнер
make clean    # удалить контейнер и образ
```

Типичный сценарий: `make build && make up && make test`.
